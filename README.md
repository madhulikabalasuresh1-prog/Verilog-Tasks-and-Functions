# Verilog Tasks and Functions

A collection of Verilog HDL programs demonstrating tasks, functions, synthesizable tasks, static vs automatic behavior, and practical digital design examples.

## About This Repository

This repository contains my hands-on practice with **Tasks and Functions in Verilog HDL**.

The programs are designed to understand how tasks and functions work, their differences, variable behavior, and their use in synthesizable digital designs.
